# Java Swing Pacman

A desktop Pacman-style game built with Java Swing.

## Overview

The project was created as a university programming assignment. The game uses `JTable` as the main map/grid component and custom rendering for walls, dots, coins, Pacman movement, and game state.

## Features

- Java Swing graphical interface.
- Menu screen and game window.
- JTable-based game map.
- Pacman keyboard movement.
- Custom cell renderer for map elements.
- Score saving and high-score handling.

## Tech Stack

- Java
- Swing
- JTable
- IntelliJ IDEA
